How To Run Game

1. Go to the supplied build and download it from the google drive
2. once downloaded open the .exe file which will start the game
3. On menu press the "Instructions" button to know how to play
4. from there press play and enjoy the experience!


Controls:
Ranger and turtle perspective (the main game) Controls: requires only the mouse using left click to interact with the main game

Turtle Race (Mini game): 
For the race, use WSAD to move the turtle dodge and weaving the obstacles. The aim of the game is to try and become first to win the mini game and earn the
maximum rewards.

Turtle Feeder (Mini game): 
For Turtle feeder, the control scheme is just your mosue only using the left button to click and drag. the goal of the game is to feed the turtles the right foods by clicking and dragging them
over the turtle while also avoid feeding them trash that also spawns with the food to gain a high as possible score.
